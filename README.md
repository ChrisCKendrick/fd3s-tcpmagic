# 🏁 LokiGarage Mazda RX-7 FD3S TCP Magic — 20B Single Turbo Build

Fourth car in the garage, and the first rotary — a 20B swap running a single big turbo with TCP Magic's full D1 angle kit and R-Magic drift-spec suspension. Smooth and NA-like off boost, but the top end hits hard once the turbo spools. Built for lock and rotation, not just grip.

## Powertrain
- Mazda 20B-REW 3-rotor (Eunos Cosmo), peripheral port, single large turbo conversion on 0.55 bar wastegate
- 467 WHP / 536 BHP crank at full boost, 400 Nm at wheels / 460 Nm crank
- Default boost 60% for a smooth NA-like ~400 whp character, full boost onset 3500 RPM, full 5000–8500 RPM, limiter 9500 RPM
- Mazda RX-7 Spirit R 5-speed — 3.483 / 2.015 / 1.391 / 1.000 / 0.719
- Final drive 4.444, competition LSD (90% power / 6% coast / 9 Nm preload), upgraded dual plate clutch (1400 Nm capacity)

## Chassis & Suspension
- 1310 kg — 50/50 front/rear (20B swap), wheelbase 2425 mm, double wishbone front and rear
- TCP Magic D1-spec angle kit — extended LCAs, short steering arms, ~61° lock, corrected scrub radius for proper FFB weight
- R-Magic (RE-Amemiya) drift-spec springs: 8.0 kg/mm front / 5.0 kg/mm rear (2.48 Hz / 1.96 Hz)
- ARB 12,000 front / 5,000 rear N·m/deg — 2.4:1 drift rotation bias
- Camber -3.0° front / -1.5° rear, minimal front toe-in, 1.5mm rear toe-in
- Track 1640 mm front / 1560 mm rear

## Brakes & Aero
- 2100 Nm max torque, 66.5/33.5 front/rear bias (cockpit adjustable)
- Full TCP Magic D1 aero — hood, roof, side canards, dive planes
- Front splitter (CL 0.16) + high-mount GT wing (CL 0.32 at 10°) — rear-biased downforce for D1 stability

## Tyres
Yokohama A052 (Comp 3) for max grip, or drop to Federal / Accelera / Valino for drift compounds.

Built to hold an angle and carry speed through it — give it a run and let me know how the lock and rotation feel.
